# 文本预览生成笔记（设计）

日期：2026-10-15

## 行为

- 右侧「划词问答」区提供「生成笔记」。无选区时禁用。
- 只摘抄与选区相交、且注释去空白后非空的注解，按原文偏移排序。
- 每条一行：`原文 注释`，条与条之间空一行。只高亮、无注释的条目不写入。
- 选区内没有可摘抄注解时提示，不建文件。

## 保存

- 与当前预览文件同一目录（根目录文件则在根目录）。
- 对话框只填文件名，默认 `{原文件名}-笔记.txt`。
- 空名、含 `\ / : * ? " < > |` 的名字拒绝；未带 `.txt` 则补上。
- 同名已存在则提示并让用户改名，不覆盖、不追加。
- 以 UTF-8 `.txt` 走现有上传。成功后提示，并通知网盘列表刷新。
