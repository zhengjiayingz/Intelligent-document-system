# F-25 音视频语义章节摘要 + 点击跳播 — 实现方案

> 日期：2026-07-25  
> 状态：✅ 代码已落地（2026-07-25）；待手测  
> 关联：PRD § F-25（v1.39）· [设计](./2026-07-25-F25-音视频语义章节摘要-设计.md)  
> 前置：ASR / 视频抽轨已交付；`VideoPlayerDialog` 摘要 Tab 已有 oneLiner/overview  

**Goal：** 音视频索引完成后，LLM 按大意输出不定长 `mediaChapters`，映射 `startMs/endMs`；播放器摘要 Tab 点击章节跳播。

**Architecture：** 在现有 `document-index` 摘要阶段（Map-Reduce 之后或旁路）对**媒体文件**增加一次 `generateObject`；结果写入 `DocumentSummary` book payload；前端扩展摘要 Tab。不新建队列、不换 ASR。

**Tech Stack：** 现有 Nest Worker、`generateObject` + Zod、ffprobe 时长、`FilesAiSummaryService`、Vue3 `VideoPlayerDialog`。

---

## 1. 已确认的决策（待你审核勾选）

### 1.1 UX

- **选定：** 播放器内「摘要」Tab = 全书概览 + **可点击语义章节列表**（段数随内容变）  
- **主路径：** 建立索引 → ready → 摘要 Tab → 点章节 seek  
- **未选：** 固定 N 段；句级字幕为主验收；独立「生成章节」按钮  

### 1.2 技术路线

- **选定：路线 M1** — 转写全文 + `durationMs` → 单次（或截断后）LLM 语义分章 → 比例映射时间 → 写入 book payload.`mediaChapters`  
- **关键点：** 媒体专用 Zod schema；索引 Processor 媒体分支调用；GET summary 原样返回；前端解析 `mediaChapters`  
- **未选：**  
  - M2 固定均分时间窗再摘要 — 违背按大意  
  - M3 多次切音频 ASR — 成本高，二期  
  - M4 新 Prisma 枚举 `video_chapter` — MVP 不必

## 3. 用户操作对照

| 步骤 | 用户动作 | 界面反馈 | 失败/边界 |
|------|----------|----------|-----------|
| 1 | 打开音/视频 | 播放器 | — |
| 2 | 建立索引 | 进度含转写 / 生成摘要 | 超时长、无音轨等同现网 |

| 5 | 再次打开 | 读库，无需重建 | force 重建除外 |

## 4. 技术设计

### 4.1 架构与数据流

```
DocumentIndexProcessor（媒体分支）
  → ASR → DocumentChunk（可仍为 1 条全文）
  → embedding（现有）
  → summaryMapReduce（现有 book，可选保留）
  → 【新增】buildMediaSemanticChapters(transcriptText, durationMs)
        → generateObject(mediaChaptersSchema)
        → normalize ratios → startMs/endMs
        → merge 进 DocumentSummary book.payload
  → status ready

前端 GET summary
  → 若 payload.mediaChapters?.length
        → 渲染可点列表
        → click → media.currentTime = startMs/1000
```

### 4.2 API

| 方法 | 路径 | 变更 |
|------|------|------|
| POST | `/api/files/:id/ai/index` | 无契约变更；媒体仍入队 |
| GET | `/api/files/:id/ai/summary` | **响应 payload 可含** `mediaChapters`、`durationMs`（向后兼容） |
| GET | `/api/files/:id/ai/transcript` | 无强制变更 |

鉴权：与现有 files AI 一致（JWT）。

### 4.3 数据 / 存储

- **新表：** 无  
- **Prisma 枚举：** MVP **不新增**  
- **复用：** `DocumentSummary`（`type=book`, `refKey=book`）  
- **payload 约定（媒体）：**

```ts
type MediaChapter = {
  index: number;
  title: string;
  summary: string;
  startMs: number;
  endMs: number;
  startRatio?: number;
  endRatio?: number;
};

type MediaBookPayload = {
  // 可与现有 novel 字段并存，或媒体改用精简字段
  oneLiner?: string;
  overview?: string;
  durationMs: number;
  mediaChapters: MediaChapter[];
};
```

- **时长：** 媒体索引时调用已有 `probeMediaDurationSec`，毫秒写入 payload

### 4.6 LLM 契约（草案）

**输入：** 转写全文（超长则截断策略见风险）、`durationHint`（可选秒数，仅供模型理解量级）。  

**输出 Zod（示意）：**

```ts
z.object({
  oneLiner: z.string(),
  overview: z.string(),
  chapters: z.array(z.object({
    title: z.string(),
    summary: z.string(),
    startRatio: z.number().min(0).max(1),
    endRatio: z.number().min(0).max(1),
  })).min(1).max(12),
})
```

**Prompt 要点：** 按主题分段；段数自定；禁止为凑数均分；章节按内容先后；`endRatio > startRatio`；覆盖全文主要部分。

**后处理：** 排序、裁剪、合并重叠、强制 `1..12`、映射 ms。

### 4.7 错误与边界

| 情况 | 处理 |
|------|------|
| `durationMs` 不可用 | 仍生成章节文案；`startMs/endMs` 置 0 或不返回；前端不可点 |
| LLM 失败 | 索引可 failed 或降级仅保留 map-reduce book（实现时二选一：**建议**章节失败不阻断 ready，打日志 + 无 mediaChapters） |
| 全文过短 | 允许 1 章 |
| 非媒体文件 | 不走本逻辑 |

## 5. 实现任务清单

- [ ] **T1** Zod + Prompt + ratio→ms 工具函数 + 单测  
- [ ] **T2** `MediaSemanticChapters` 服务：`generateObject` + normalize  
- [ ] **T3** Processor：媒体分支在摘要阶段取全文、`durationMs`、调用 T2、merge 进 book payload  
- [ ] **T4** 确认 GET summary 已返回完整 payload（一般无需改）  
- [ ] **T5** `VideoPlayerDialog`：解析 `mediaChapters`、列表 UI、点击 seek  
- [ ] **T6** 手测：短音频 / 中长视频各一；段数不同；跳播；force 重建；文本 PDF 摘要无回归  

---

## 6. 验收标准

- [ ] 媒体索引 ready 后，summary payload 含 `mediaChapters`（长度 1～12，随内容变）  
- [ ] 每章含 `title`、`summary`、`startMs`、`endMs`  
- [ ] 前端点击章节跳到对应时间并播放  
- [ ] 不强制所有文件同为 5 段  
- [ ] ASR 一坨时仍可生成可点章节  
- [ ] 文本文档摘要路径无回归  
- [ ] 相关单测通过

## 7. 测试计划

- **单测：** ratio 映射；非法 ratio 修正；章节数裁剪；schema parse  
- **手测：**  
  1. 短 mp3：≥1 章，可跳  
  2. 较长 mp4：多章且段数≠5（若模型给出）  
  3. 重建索引后章节更新  
  4. PDF 索引摘要仍正常

## 8. 风险与后续

| 风险 | 缓解 |
|------|------|
| 时间估算偏差 | 产品接受「附近」；二期接真 segments |
| 超长 transcript 超上下文 | 截断 + Prompt 说明「基于节选」；或先粗分块摘要再分章（二期） |
| 与 novel book 字段混杂 | 媒体 payload 以 `mediaChapters` 为准；UI 优先读该字段 |

**明确延后：** 句级字幕、切音频多次 ASR、分享页、F-41。
