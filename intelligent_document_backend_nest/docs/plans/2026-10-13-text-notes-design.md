# 文本预览划词注释 — 设计文档

> 日期：2026-10-13  
> 状态：已评审

## 目标

在文本分块预览里，对选中的原文做 Kindle 式注释：可以只高亮，也可以写一句说明。注释按当前用户和这篇文件保存，下次打开仍在原文上。

## 范围

| 做 | 不做 |
|----|------|
| 文本分块预览（txt 等） | PDF 及其他预览 |
| 选区旁「添加注释」 | 右侧注释列表、标签、导出 |
| 高亮持久化；正文可空 | 分享链接里展示注释 |
| 点高亮查看、修改、删除 | 服务端每次保存重读全文核对原文 |
| 多种颜色（色板 + 自定义，见 2026-10-15-text-note-colors-design.md） | 全局默认色、按色筛选 |

## 交互

1. 划词松开后，选区旁出现「添加注释」。
2. 卡片里是可空的多行输入，以及保存、取消。
3. 卡片内可选颜色（默认淡黄）；保存后按所选色持久高亮。只高亮、不写字也可以保存。
4. 再次点开高亮，同一张卡片里可以改正文、改色或删除。
5. 高亮允许重叠。点到重叠处时，打开范围更小的那一条；范围相同则打开最近创建的那一条。

临时划词高亮和已保存注释高亮分开画，互不覆盖。

## 锚点

不记显示行号。「流式重排」会合并段内换行，行号会变。

每条注释保存：

- 原文起止位置：把 `\r\n` 和 `\r` 统一成 `\n` 之后的字符偏移，`startOffset < endOffset`
- 选中时的原文片段 `quote`

打开预览时，前端用已加载原文把偏移映射回当前显示行（原文换行或流式重排）再画高亮。`quote` 与该切片不一致时，标成「原文已变化」，不挂到别的句子上。注释落在尚未加载的后文时先保留数据，滚到对应分块再画。

## 数据

表 `file_text_notes`：

| 列 | 说明 |
|----|------|
| id | 主键 |
| user_id | 注释所属用户 |
| user_file_id | 文件 |
| start_offset / end_offset | 归一化原文中的字符起止 |
| quote | 选中原文，长度上限 |
| content | 注释正文，可空，长度上限 |
| color | `#RRGGBB`，默认 `#FFD666` |
| created_at / updated_at | 时间 |

索引 `(user_id, user_file_id)`。删除用户或文件时级联删除注释。

## 接口

均需登录，且只能操作自己的文件。挂在现有 `files` 路由下：

- `GET /api/files/:id/text-notes`：打开预览时拉取全部
- `POST /api/files/:id/text-notes`：body 含 `startOffset`、`endOffset`、`quote`、可选 `content` / `color`
- `PATCH /api/files/:id/text-notes/:noteId`：可改 `content` 与/或 `color`
- `DELETE /api/files/:id/text-notes/:noteId`

校验：起点小于终点、偏移不为负、`quote` 与 `content` 未超长、`color` 为合法 `#RRGGBB`。文件不存在或不属于当前用户时返回 404。

## 前端

`TextChunkPreviewDialog` 打开时拉取注释。保存、修改、删除走上述接口。已保存注释按条用彩色覆盖层绘制；临时划词仍用蓝色选区高亮。流式重排开关切换后重算映射并重画。
