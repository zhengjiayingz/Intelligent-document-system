# 文本预览划词注释 — 多种颜色

> 日期：2026-10-15  
> 状态：已评审

## 目标

注释高亮支持用户自选颜色：常用色一键选，也可自定义任意 `#RRGGBB`。颜色随注释持久化，下次打开仍按该色绘制。

## 决策

| 项 | 选择 |
|----|------|
| 选色方式 | 5 色色板 + Element Plus 取色器 |
| 默认色 | `#FFD666`（原淡黄）；旧数据迁移补默认 |
| 何时改色 | 新建与编辑均可；与正文同一张卡片，点保存一并提交 |
| 存储格式 | `#RRGGBB`，服务端规范为大写 |
| 绘制 | 已保存注释用彩色覆盖层矩形；临时划词仍用蓝色选区高亮 |

预设色：黄 `#FFD666`、绿 `#A8E6A1`、蓝 `#9EC9FF`、粉 `#FFB3C6`、橙 `#FFC58A`。

## 不做

全局默认色设置、按颜色筛选列表、透明度滑条、PDF 预览着色。

## 数据

`file_text_notes.color`：`VARCHAR(7)`，默认 `#FFD666`。

## 接口

- `POST` body 可选 `color`
- `PATCH` 可同时改 `content` 与 `color`
- `GET` 每条返回 `color`

非法色返回 400。缺省颜色时用默认淡黄。

## 前端

注释卡片正文上方：5 色圆点 + 自定义取色器。创建默认淡黄；编辑回填已存色（非预设时仅取色器显示该色）。高亮按条上色；滚动与流式重排后重画。
